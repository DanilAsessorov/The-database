# Проект: Анализ вакансий с hh.ru

## Описание
Проект для курсовой работы по базам данных.
Собирает данные о компаниях и вакансиях с hh.ru, сохраняет в БД SQLite,
предоставляет интерфейс для анализа данных.

## Установка
1. Установите Python 3.8+
2. Установите зависимости: `pip install -r requirements.txt`

## Использование
1. Запустите сбор данных: `python api/hh_api.py`
2. Запустите программу: `python src/main.py`

## Структура проекта
- `api/hh_api.py` - работа с API hh.ru
- `database/` - модули для работы с БД
- `src/main.py` - главная программа
- `requirements.txt` - зависимости
